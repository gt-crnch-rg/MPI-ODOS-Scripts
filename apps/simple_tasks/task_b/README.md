# Task b: OpenMP on the DPU

[`omp_parallel.c`](omp_parallel.c) nests `#pragma omp parallel` inside
`#pragma omp target`. The parallel region runs on the DPU's Arm cores, so the
DPU prints one line per OpenMP thread: 16 on a BlueField-3.

## Run

From `apps/simple_tasks`, after `./docker_compile.sh` (see the
[README](../README.md)):

```bash
./dpu_service.sh <dpu> start
./docker_run_task.sh out/tasks/b_omp_parallel
```
